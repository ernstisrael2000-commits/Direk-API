# Development Workflow


IMPORTANT :

Ne jamais construire tout le projet en une seule fois.


Ordre obligatoire :


Phase 1

Importer design ZIP.

Vérifier :

- pages visibles
- navigation
- responsive


Attendre validation.


Phase 2

Configurer Supabase.


Créer :

- tables
- sécurité
- fonctions serveur


Attendre validation.


Phase 3

Créer les fonctions API une par une.


Après chaque fonction :

- tester
- montrer résultat
- attendre confirmation


Aucune étape suivante sans validation.
