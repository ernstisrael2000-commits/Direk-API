Elite Reseller

Documentation API

Intégrez Direct API dans votre application pour automatiser les recharges et la vente de produits digitaux.

Authentification

Toutes les requêtes API doivent inclure votre clé API dans le header Authorization.

Request Header
Authorization: Bearer dk_live_...

Recharge Directe

POST/api/v1/recharge

Paramètres Body

player_id

L'identifiant unique du joueur.

String
product_id

Code du produit (ex: ff_100d).

String

Exemple de requête

JSON
{
  "player_id": "29384812",
  "product_id": "ff_100d"
}

Réponse Succès (200 OK)

{
  "status": "success",
  "transaction_id": "TRX-9982",
  "remaining_balance": 125300
}

Codes d'erreur

401 UnauthorizedClé API invalide ou manquante.
402 Payment RequiredSolde du wallet insuffisant.
404 Not FoundProduit ou ID joueur inconnu.
