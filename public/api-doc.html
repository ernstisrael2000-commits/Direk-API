Direct API v1

Intégrez les recharges de jeux dans votre application

Une seule API REST pour déclencher des recharges (diamants, gems, passes…) directement depuis votre site ou bot. Vous gérez les prix, Direct API gère la livraison.

Base URL: /api/v1 Auth: X-API-Key Format: JSON

Authentification

Chaque requête doit inclure votre clé API dans le header X-API-Key. Retrouvez votre clé dans votre profil.

HTTP Header 
X-API-Key: dk_live_votre_cle_api

Ne partagez jamais votre clé API. En cas de compromission, régénérez-la depuis votre profil — l'ancienne est immédiatement révoquée.

JavaScript (fetch) 
const res = await fetch('/api/v1/orders', {
  method: 'POST',
  headers: {
    'X-API-Key':      'dk_live_votre_cle_api',
    'Content-Type':  'application/json',
  },
  body: JSON.stringify({
    product_id: '{{ firstProductId() }}',

  }),

const data = await res.json();
if (data.ok) {
  console.log('Commande réussie', data.commande_id);
} else {
  console.error('Erreur', data.error);
}

Codes d'erreur

400

Bad Request

Paramètre manquant ou invalide (ex : product_id absent).

401

Unauthorized

Clé API manquante, invalide ou compte suspendu.

402

Payment Required

Solde wallet insuffisant pour ce produit.

404

Not Found

Produit introuvable ou inactif.

422

Unprocessable Entity

ID joueur invalide ou paramètre rejeté par le fournisseur.

429

Too Many Requests

Limite atteinte : 60 commandes/minute par compte.

502

Provider Error (remboursement auto)

Le fournisseur a échoué. Votre solde est automatiquement remboursé.

Flux d'une commande

1

Vérification paramètres

product_id valide, params complets, solde suffisant.

2

Validation joueur (Free Fire)

L'ID est vérifié en temps réel. Si invalide → erreur 422, aucun débit.

3

Réservation atomique

Le solde est débité et la commande créée en une seule opération.

4

Envoi au fournisseur

Direct API transmet la commande à FazerCards en coulisse.

Résultat

Succès → status: "success". Échec → remboursement automatique status: "refunded".
