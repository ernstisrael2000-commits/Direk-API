Vue d'ensemble

Intégrez les recharges de jeux dans votre site ou application. Vous gérez vos prix, Direct API orchestre la livraison via les fournisseurs.

Base URL: /api/v1 Auth: X-API-Key Content-Type: application/json

Authentification

Ajoutez votre clé dans chaque requête via le header X-API-Key. Clé disponible dans votre profil.

HTTP Header 
X-API-Key: dk_live_votre_cle_api

Ne partagez jamais votre clé. En cas de compromission, régénérez-la depuis votre profil — l'ancienne est immédiatement révoquée.

Params — Free Fire LATAM

ID numérique du compte Free Fire. Visible dans le jeu → Profil, sous le pseudo.

String

L'ID est vérifié en temps réel avant débit. Si l'ID est invalide → erreur 422, aucun montant prélevé.

Exemples complets

cURL 
# Passer une commande
curl -X POST https://votre-app.com/api/v1/orders \
  -H "X-API-Key: dk_live_votre_cle" \
  -H "Content-Type: application/json" \
  -d '{
    "product_id": "{{ firstId() }}",
    "params": { "player_id": "123456789" }
  }'

# Vérifier le statut
curl https://votre-app.com/api/v1/orders/UUID_COMMANDE \
  -H "X-API-Key: dk_live_votre_cle"
JavaScript (fetch) 
const res = await fetch('/api/v1/orders', {
  method: 'POST',
  headers: {
    'X-API-Key':     'dk_live_votre_cle',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    product_id: '{{ firstId() }}',
    params:     { player_id: '123456789' },
  }),
});

const data = await res.json();

if (data.ok) {
  console.log('✓ Commande réussie', data.commande_id);
} else {
  console.error('✗ Erreur', data.error);
}
